DEL SOL ITALIC v1.000
Headline typeface for Del Sol High School (Jaguars), built from the DEL SOL / JAGUARS lettering.

FILES
  otf/Del-Sol-Italic.otf    - install on Mac or Windows; upload to Canva or Adobe Express
  ttf/Del-Sol-Italic.ttf    - Windows / Office alternative
  woff2/Del-Sol-Italic.woff2, woff/Del-Sol-Italic.woff - websites and Wix

NOTES
  All caps: lowercase keys type capitals.
  No accent marks: A, E, N, U etc. print without accents and there is no ¿ or ¡.
    Set Spanish text in Open Sans.
  No (TM) (C) (R) symbols.
  Display face only. Never use it to retype the DEL SOL or JAGUARS word marks.
