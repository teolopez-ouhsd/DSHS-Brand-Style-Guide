# Del Sol Jaguars Brand Guide

Brand style guide for Del Sol High School (Oxnard Union High School District): official logos, sport logos, colors, uniform and embroidery specs, accessibility, the Del Sol Italic typeface, and usage rules.

## Publish on GitHub Pages

1. Create a new repository (for example `Del-Sol-Brand-Style-Guide`).
2. Upload everything in this folder: `index.html`, `logos/`, `sheets/`, `fonts/`, `zips/`, the three .zip files, `.nojekyll`, and this README.
3. In the repo, go to **Settings > Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, and save.
4. After a minute the page will be live at `https://<your-username>.github.io/<repo-name>/`.

## What's inside

- `logos/svg`, `logos/png`, `logos/pdf`: 113 logos, each exported as its own file from the Brandiose Illustrator file (`del_soul_BUILD.ai`, v11/8/22).
  - 13 marks: `delsol-<mark>-<version>` (versions: full-color, one-color-orange, one-color-gold, grayscale, black-white; the DS monogram uses orange, gold, black).
  - 60 sport logos: `delsol-<sport>-<lockup>` (lockups: del-sol-stacked, jaguars-stacked, del-sol-arched, horizontal). Full color only.
  - PNGs are 2400px on the long side with transparent backgrounds. PDFs keep the Pantone spot colors.
- `zips/delsol-<mark>.zip`: every version of one mark in all three formats.
- `del-sol-jaguars-logos.zip` (the 13 marks), `del-sol-jaguars-sport-logos.zip` (all sport logos), `del-sol-italic-font.zip`.
- `logos/retired/`: watermarked preview of the retired Jaguar Profile (shown on the page only; its logo files were removed).
- `sheets/`: the original Brandiose reference sheets as PNG plus one PDF.

## Updating files

Replace files in `logos/` with the same names, then rebuild the matching zip files.
